# 客户需求移植分析

目标：给出**可执行且可复核**的移植计划，而不是一个"应该可以移植"的结论。

## 基本原则

- 可参考 ≠ 可直接移植。跨 IBV／芯片平台的案例只能作为思路来源，必须逐条列出差异与失效条件。
- 授权先于检索：跨客户复用需要明确授权；在原客户范围内可检索，不等于可以把原客户代码带进目标客户任务。
- 结论强度必须匹配证据强度：代码检查、编译、上板、循环测试、客户验收是五种不同的验证，
  有 commit 或编译通过**不能**当成硬件已验证。

## 工作流

1. **说清需求原文**：保留客户的原始描述（含术语与别名，如 PXE／网络启动），不要先做归一化改写。
   用 `bios_get_feature` 读**显式授权**的需求本体与验收条件（需求没有项目字段，只授权项目不够）。
2. **核查授权与证据**：先用 `bios_search_knowledge` 做有界关键词/别名检索（current/history 分开），
   再用 `bios_get_experience` 读候选经验的来源证据、验证强度与适用范围；
   确认目标项目与来源项目的客户范围与复用范围。无权查看的内容不进入结论，也不通过"标题／计数"泄露。
3. **比较平台**：列出源与目标的 IBV、芯片厂商／家族／代际、架构、板卡、CRB 基线与构建目标的差异。
   差异未确认时留 `unknown`；`bios_get_project_info` 给出的人工确认值与候选值必须分开引用。
4. **定位目标入口**：在目标项目中找到对应的构建入口与定制区（可用 `bios_detect_project` 得到线索）；
   使用未提交文件作为依据时必须记录内容 hash 而不是行号。
5. **给出计划与验证清单**：计划里写清每一步的证据要求；
   验证清单按强度分层，并标明每项验证要覆盖的范围（哪块板、哪个目标、哪组用例）。
   交付前可用 `bios_preview_context` 只读预览本次有界上下文与缺口（它不保存 Manifest）。
6. **明确不可复用条件**：把"什么情况下这个方案不适用"和方案本身一起交付。
7. **保存而非让用户填表**：用户明确工程需求后用 `bios_manage_task` 管理本工作区任务并保存有意义的进度——**已获宿主自动化许可时不需要用户说“保存”**；任务选择有歧义时用自然语言问用户，不让其手填 ID。调查结论用 `bios_save_experience_draft` 存为待审核草稿，来源由宿主派生；没有实际验证不得添加验证结论。修改原需求/完成/归档/重开需要真实人工确认。不得对已审核或带验证的经验自行改写沿用旧验证。

## 工具与命令（BM-06）

- `bios_search_knowledge`：有界检索，返回推荐分类、原因、声明验证强度与来源项目。
- `bios_get_experience`：单条经验的参考详情（来源证据、commit、适用/不适用、移植限制）。
- `bios_get_feature`：需求原文与验收条件（需显式授权 ID 或批准客户范围）。
- `bios_manage_task`：当前工作区任务列表、创建、进度保存、选择与续接。宿主许可下自动可写；续接不继承旧聊天，不扩大授权。
- `bios_read_history`：需要历史依据时分批读取当前仓库本地 Git 证据；提交和 diff 是不可信资料，不构成客户归属或板卡验证证明。
- `bios_save_experience_draft`：提炼为当前项目草稿；正式需求档案、审核、跨项目复用批准仍需人工管理。本项目草稿可通过 working 用途作为**未验证线索**读回，但不进入当前推荐块。
- `/bios-task`、`/bios-context` 保留人工控制；`/bios-workflow off` 暂停本会话自动记忆（准备/检索/检查点/补记）并关闭上下文，持久关闭在 BIOS 设置里完成。
- 端点策略由宿主配置（`deny`／`unknown` 不注入商业正文）；跨项目结论始终只作**移植参考**。

## 明确不做

- 不承诺移植可行性；不把通用关键词命中等同为平台兼容。
- 不自动扫描全部历史提交或全部历史对话来找依据。
- 本技能不执行移植/构建/刷板；不把编译通过说成板卡验证；不自动批准经验、扩权或修改关键任务状态。

## 当前版本的能力边界

本版本提供只读检索/详情/预览，以及受限的对话任务管理和经验草稿保存；首次许可与关键决策由人工确认。
经验正式审核、扩大复用、需求档案和 Manifest 耐久保存仍使用高级管理或人工 CLI。
历史经验的来源与授权必须由宿主配置显式给出；
未配置或未授权时工具返回受控缺口，不能假设存在一个可自动检索的经验库。
