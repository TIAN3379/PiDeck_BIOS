# BIOS Agent 产品定义

状态：v0.8.0 首轮身份改造

## 一句话描述

BIOS Agent 是一个由 TIAN3379 维护、面向个人日常开发的本地 Agent 桌面工作台，安装后可以像普通 Windows 应用一样从桌面图标启动。

## 用户与问题

- 目标用户：当前首先服务维护者本人，后续再根据真实使用反馈扩展。
- 核心问题：源码开发模式每次都要打开终端并执行启动命令，不适合日常使用。
- 核心场景：从桌面快捷方式启动，管理本地项目和 Agent 会话，使用 Git、终端及模型配置能力。

## 当前边界

- 基于 PiDeck 二次开发，遵循 MIT License 并保留上游署名。
- Agent 行为仍由外部 pi CLI 提供，桌面应用只负责工作台层。
- 首轮不重写内部架构，不改 `PIDECK_*` 兼容协议和内置扩展文件名。
- 首轮不承诺代码签名、公证或公开商业发行。
