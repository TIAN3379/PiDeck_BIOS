# BIOS Agent 使用指南

适用版本：v0.9.3，2026-10-07。

## 安装与首次准备

运行 Release 中的 `BIOS-Agent-0.9.3-setup.exe`，安装后从桌面或开始菜单启动，不需要复制软件源码。

本次为 Windows x64 预览版，建议手动下载安装；Stable 检查更新不承诺展示预览版。

按环境指引准备 Node/npm 与 Pi CLI，需要网络下载；已有环境可指定现有 Pi。配置模型服务、模型和凭据后 AI 才能工作。BIOS 扩展的回归基线是 Pi 0.87.1；更新版须另行验证兼容。

BIOS 工程、编译工具链、旧知识数据不包含在安装包里。读取 Git 历史还需要 Git。干净电脑完整安装/首次下载尚需真实验证。

## 接入工程

1. 左侧“项目”添加源码目录，打开工程。
2. 初次接入弹窗核对名称、源码目录和知识根；可创建应用数据目录下的默认库，也可选择已有库。
3. 确认项目/目录许可。模型资料外发许可有单独明确提示，绑定实际 provider、模型、API 地址；换服务后可能需重新确认。
4. 已接入工程不必重接。右侧只显示必要状态，可按需打开“管理”或“查看知识库”。

普通“聊天”不是 BIOS 工程，不自动登记。取消接入撤回许可和关联，历史知识保留但不再列为当前已接入。旧档案经确认复用原 ID；冲突不自动合并。

## 日常开发直接对话

```text
分析这个项目的 IBV、芯片平台、板卡和构建入口，给出源码证据。
无法确认的内容列候选，不猜客户归属，不改代码。
```

```text
调查 S3 唤醒黑屏，先检索本项目工作线索和合格历史经验，再定位源码。
区分证据、推断和待验证项；本轮只调查，不编译、烧录、提交或推送。
```

```text
给出将历史 PXE 定制移植到当前平台的方案。
先比较 IBV、芯片、协议、板卡和验证基线，不直接复制补丁。
```

启用自主工作流且完成授权后，扩展自动准备背景、按需检索工作线索、记录实际进度和普通经验草稿，不必每次提醒保存/检索。自动保存不等于已审核、已验证或允许跨项目复用；没有实际写入回执，AI 说“记住了”不算已保存。

身份、客户归属、正式需求、经验批准和资料许可仍由你确认。知识许可不是烧录、源码修改或 Git 推送许可。

## 任务不是对话

对话是交互窗口；任务是知识库中持续跟踪的工程目标，有状态、决策、待办、阻塞和证据。任务可跨多个对话；一个对话也可能涉及多个任务。

```text
为“调查 S3 唤醒黑屏”建立任务，记录证据、待办和阻塞。
只记录调查计划，不把未知测试写成通过。
```

新对话打开同一工程，明确说“继续上次 S3 调查”。AI 重读磁盘任务和当前源码；多个候选时询问选择，不擅自续跑旧操作。没有保存任务时，聊天列表不会变成任务列表。管理入口可查看任务与交接预览。

## 从旧项目沉淀经验

先选一个你熟悉的 Bug，而不是一次总结整个量产库：

```text
只读分析最近 10 个提交，找客户定制和 Bug 修复。
结合 diff 与源码保留提交哈希、文件和证据。
未知根因、客户、测试结果明确标未知，保存待审核经验草稿。
不修改源码，不提交或推送。
```

Git 提交说明不是客户需求权威，也不能证明补丁上板通过。补齐适用范围和测试条件后人工审核。

同一知识库可存多个项目，但不是任意互读。跨项目复用须满足来源授权、客户/需求范围、复用资格和平台条件。不同 IBV/Silicon 的历史成功只能作线索，当前工程仍需验证。

## 查看与编辑知识库

右侧“查看知识库”支持分页/筛选经验和客户需求、查看详情与来源、编辑保存；无需启动 AI，不扩大模型权限。

未保存退出会询问是否放弃；版本冲突先重读，不强制覆盖其它会话。已审核经验修改前须确认退回草稿。高级详情便于核对完整记录，日常不必手填内部 ID/revision。

当前存储是本地结构化 JSON，不是向量库，也不训练模型。AI 按授权与预算读取命中材料，不会每轮上传整库。检索有扫描/读取上限，“没命中”不等于历史未做过。

## 数据、暂停与备份

- 桌面数据默认在 `%APPDATA%\\PiDeck`，聊天由 Pi 管理；BIOS 知识在指定知识根，和软件源码/安装目录分离。
- 停止相关会话写入后从 BIOS 设置离线备份；恢复到新目录，不覆盖原库。源码/Git/聊天另备份。
- 不在运行中手改 JSON、删锁或复制活动库；迁移知识根不自动重绑定旧源码路径。
- `/bios-workflow off` 暂停当前会话自主工作流；`/bios-context off` 仅关显式任务上下文。长期设置和撤权从管理/设置处理。

## 常见提示

| 提示 | 处理 |
| --- | --- |
| 未配置/未初始化知识库 | 完成接入与创建确认；仅选择目录不是建库成功。 |
| 宿主未授权项目/需求/客户 | 核对工程接入和来源许可，不盲目放开所有资料。 |
| 模型 unknown/未确认 | 核对实际模型服务，切换后重确认。 |
| 配置已保存，待重开 | 旧 Pi 进程尚未采用设置，用重开入口后再验证。 |
| 无历史经验命中 | 区分未授权与无合格结果，检查关键词、审核和复用范围。 |
| 接入绑定冲突 | 核对真实目录与旧关联，不自动合并。 |
| 部分保存/版本冲突/证据变化 | 重读当前记录与源码，补缺口，不沿用旧“已验证”。 |

软件辅助调查、修改与知识沉淀，不替代编译环境、固件回归、上板和量产验收。
