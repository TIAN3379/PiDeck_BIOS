# 下一步开发

基线：v0.9.3，2026-10-07。按实际缺口迭代，不沿用几十轮结束的任务重复开工。

## P0：真实使用验证

1. 干净 Windows x64：只带 setup，验证首次 Node/npm/Pi 下载、模型配置、建库、重启/升级。记录 Pi 版本，新版验证扩展兼容。
2. 熟悉 Bug：只读调查 → 草稿 → 新对话续接 → 人工审核 → 再检索。对比工程师已知事实，不以 AI 自述证明保存或验证。
3. 确认普通聊天隔离、已接入不重复登记、取消刷新过滤、旧档案按钮有反馈、知识离线编辑。

真实源码修改、构建、烧录和 Git 操作前明确权限；以上清单不默认授权。

## P1：经验质量与检索实效

以少量已完成项目评估历史证据准确率、漏检、重复草稿、跨平台适用性。先改实际高频失败，再增加设施。厂商 Skills 需合法资料和工程验证，不加空目录声称适配。

## P2：时态增强

按[分层记忆设计](layered_memory_temporal_design.md)补充必要历史/耐久指纹。先评审契约、预算、兼容与备份恢复，再实现，不推翻 JSON、revision、锁、journal 和 Pi 扩展底座。

## 暂缓

向量服务、全仓 AutoDream 扫描、自动审核、云端团队权限、自动烧录、全平台统一编译调度。先证明实际收益并解决权限/数据治理。

每次只更新当前文档、测试/发布清单及必要架构说明，不新建重复轮次交接；阻塞写明复现、影响和验证范围。
