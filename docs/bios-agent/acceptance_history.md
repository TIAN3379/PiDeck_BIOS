# BIOS Agent 早期验收摘要

整理：2026-10-01。本文是历史证据索引，不是当前开发指令；当前入口见 [README](README.md)，最新结论见 [第六轮验收](round6_acceptance.md)。

## 第一轮与 BM-01R

- 骨架加载/契约测试当时 20 通过；发现默认知识根、安全 ID、单项目多工作区快照、有界异步取消、授权根、隔离 RPC/安装链路等 R1～R6。
- 整改后 45 用例通过，但没有证明全部边界已关闭；后续出现 F1～F4。
- 当前这些基础问题已经有长期回归，不重新生成 Package/Pi 执行循环。

## 第二轮与 BM-01R2

- 第二轮独立复跑 45 通过；发现保留名带点后缀的规则不一致、Windows 非完全限定根、空/小目录取消、相对额外授权根 F1～F4。
- 收尾后 60 用例通过；统一 ID 规则、完全限定路径、授权来源和异步取消策略。
- 通过测试数量不等于句柄生命周期通过，第三轮仍发现 G1。

## 第三轮与 G1

- 60 用例通过，但 opendir 成功后的取消检查在 try/finally 外，目录句柄只能由 GC 兜底关闭。
- G1 在后续存储基础轮修复，增加生命周期计数和子进程 GC 诊断；现在已关闭。
- 原 BM-02A 设计仍保留在 [存储基础需求](bm02a_development_plan.md)，不再按其中旧提示词开工。

## 第四轮与 S1～S5

- 第四轮独立复跑 89 用例，88 通过、1 文件符号链接权限 skip；G1 关闭，存储主体成立。
- S1：直写最终目标的 wx 回退暴露半文件；已删除回退，硬链接不支持时 fail-closed。
- S2：列表未共用项目归属校验；已共用记录解释链。
- S3：过期 stat 导致读取合法前缀、末 IO 点取消遗漏；读取/列表/竞争等待已关闭；发布取消在第五轮仍有剩余，现已由 BM-02B 的 B0 关闭。
- S4：非法候选整体失败、异常输出预算/非法限额/链接诊断；已关闭。
- S5：重复项目 ID、矛盾过滤条件、多工作区任取首个；已关闭。
- 当时的具体设计依据见 [存储收尾任务](bm02a_remediation_plan.md)和[实施记录](bm02a_remediation.md)。
